# NDCRM UX/UI Hero Screen

Animated NDCRM landing-page hero built with React, TypeScript and Vite.

Features include a scroll-linked parallax sequence, four feature cards, a responsive product preview and a custom WebGL1 Mesh Drift background.

## Development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm preview
```
